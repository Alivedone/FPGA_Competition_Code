# 三页HMI接口约定

页面名main/history/detail，文本全局作用域；热区可保持私有。编码GB2312，115200 8N1，bkcmd=3，recmod=0。请求帧与控件名必须匹配UART部署与联调.md。

- main文本：tClass、tId、tScore、tValid、tState、tLink、tWinMs、tFwdMs、tAge。
- history文本：r0Id/r0Class/r0Score/r0Ms，按相同规则到r4；tCount、tNew、tPage。
- history热区：bRow0～bRow4、bPrev、bNext、bHome。
- detail文本：tRecord、tTask、tModel、tClass、tScore、tPl、tIn、tFwd、tOut、tWinMs、tTotal、tClean、tStart、tHint。
- main/detail的bHistory均跳到history；history.bHome跳到main。

下行指令文本后追加三个实际FF字节。命令串内的引号、反斜杠、控制字符由软件清理；不可编码字符替换为问号，单字段最多32个Unicode字符再转换，限制到当前64字节及以上文本缓冲。

旧双页布局中的main.tTask/main.tCount/main.tStart、detail.tMode等不再写入；不要把旧双页HMI拿来忽略错误运行。
