# 离线GUI测试示例

在GUI点击“加载离线示例”，选中任务后点击“查看识别详情”。不需要板卡连接。

- real_cpu：9个输入对象的真实PC Icraft HostBackend ResNet输出。复用已验证的CPU输出，与new_data对应输入首窗逐字节核对；不是NPU结果。预测按模型实际输出，不按文件夹名称强行改标签。
- image_demo：9个覆盖标签0～8的图片映射演示。真实输入轨迹配合人为指定类别，只验证九张图片和雷达显示，不是模型推理，不用于评估准确率。

每个task目录可通过“加载历史任务”单独打开。频谱及轨迹快照已包含，换电脑不依赖原始F盘路径。index.json区分来源；每个client_report.json和GUI状态均标注离线/人为演示。没有伪造服务READY或板端执行记录。
