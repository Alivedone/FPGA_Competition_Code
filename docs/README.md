## 各阶段分别说明什么

1. **早期骨干探索**：用20轮配置评估频谱网络及Res2Net。结果来自开发集，不能与最终30轮、量化后的板端结果混作一组。
2. **训练策略筛选**：在ResNet34上比较Adam、余弦调度、AdamW和均衡随机抽窗；A与D有三个种子，B/C只有一个。A/B/C/D是实验配置，不是新的网络名称。
3. **校准选样**：固定历史ResNet34权重，比较原54窗、重排54窗和代表性54窗；评价用内部开发集，不能称为最终ResNet18固定测试结果。
4. **最终三模型选型**：同一最终训练策略和54窗校准，比较ResNet18/34/50的浮点、INT8 Host和真实板端结果。ResNet34复用历史同配置权重，18/50补训seed42；候选选择历史并非完全对称。
5. **工程调用优化**：在保持PL/PS接口条件下检查回调、同步、输出校验和forward开销，另用原版/F完整固定测试确认结果一致。此处主要是历史ResNet34工程，不用其时间代替最终ResNet18 SDK均值。

所有公开结果以JSON、NPZ和逐请求CSV支持。开发集指标用于方案选择，固定测试数据也已被历史工作评价，窗口彼此相关，不能把窗口数当作独立目标实例数。
