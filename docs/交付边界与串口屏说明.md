# 交付边界与串口屏说明

## 包含的内容

本包整合PC上位机、PS应用源码、PL工程和IP资源、最终ResNet18部署模型、18组演示数据、启动组件，以及模型训练和转换量化复现材料。最终PT、ONNX、ZG JSON/RAW均保留，未收录其他候选模型权重或全部训练中间checkpoint。

固定测试集的标准化频谱缓存已提供，可直接在PC复核250份MAT、7239个窗口的预测。完整原始训练MAT需另行准备；开发集原始频谱缓存可从数据划分清单重建。训练、开发和固定测试的保存预测及指标均保留。

## 配套环境

- 开发板需要匹配FMQL30TAI硬件、DDR配置和本项目PL的BSP、驱动与系统镜像。
- 板端需要配套Icraft 3.36.1 ARM64开发/运行环境以及C++构建工具。
- `sd`目录提供启动组件，不是包含Linux根文件系统的完整SD卡镜像。它们保持原始压缩包中的版本，不能据此宣称已重新验证与所有硬件配置兼容。
- 完整系统镜像、SDK安装包、Python虚拟环境和公开数据集全集不随代码重复打包。

## 串口屏资源的实际状态

包内已包含UART显示、历史查询源码，以及三页事件代码、控件属性表和通信协议，位于PS工程的`hmi_interface`目录。

当前收到的材料中未找到屏幕原生`.HMI`编辑工程及对应`.TFT`下载文件，因此没有将其虚构或用截图代替。使用已经写入兼容界面的屏幕可继续联调；若要从空白屏完整复现外观，还需补充团队实际使用的这两类资源，或按控件协议重新制作并验证界面。

## 验证范围

本次为PC侧整合和打包：检查模型身份、PS源码清单、PL工程文件引用、18组演示输入、上位机启动、保存预测复算及完整ONNX测试。没有重新连接开发板，也没有重新构建PL或烧录屏幕。

已有板端精度、时延证据继续保留，并与本次包装层验证分开说明。最终提交前如需宣称整机重部署通过，应使用配套硬件执行一次实际上传到屏幕更新的验收。
