# 最终ResNet18/34/50对照依据

保存三个候选的训练history/metrics、完整开发/固定测试的FP32、INT8 Host和板端logits，以及每模型三轮各1080次的请求时间CSV。

固定训练条件：seed42、30轮、batch64、AdamW、余弦退火、类别→MAT→起点均衡随机抽窗；固定单通道10×512、数据划分、标准化和54窗校准。ResNet34复用历史同条件权重，ResNet18/50补训seed42；候选选择历史不同，不把这次工程取舍称为架构普遍结论。

最终ResNet18/34/50板端整段准确率为92%/92%/88%，SDK均值3.0841/5.0372/6.3679ms。每份MAT先对所有合法窗口softmax等权平均，再计一个最终判决。SDK时间不含外部PL、网络、显示或等满10帧数据的观测时间。

最终ResNet18权重已在赛事代码包提供；另两个候选保存在Releases研究权重附件中。此目录不重复发布三套完整Icraft中间图及安装环境。
