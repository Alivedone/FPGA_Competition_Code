# 早期骨干网络探索

保留ResNet18、ResNet34、ResNet50与Res2Net-50 26w×4s的历史20轮频谱实验记录。此阶段用于理解骨干结构与输入适配，和后续最终30轮训练策略、INT8板端选型分开。

对应研究权重位于Releases附件的early_20epoch目录。Res2Net原结构来源记录为作者项目`Res2Net/Res2Net-PretrainedModels`；本阶段的训练权重是本任务频谱适配结果，不是直接使用ImageNet RGB模型。数据归一化和单通道短时间轴约定与技术报告一致。

此目录包含保存指标和学习曲线，并不构成对某骨干普遍优劣的证明。最终部署模型仍是ResNet18。
