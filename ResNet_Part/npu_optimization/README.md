# 工程调用优化与准确率对照

这是历史ResNet34工程的NPU调用验证材料，覆盖逐项A—F策略、重复/A-B-A压力记录和原版/F完整固定测试对照。A—F是运行策略，不是六种网络。

优化在既有工程副本开展，保持PL/PS接口，检查回调、逐算子同步、额外forward及重复输出核对的开销，同时保留必要的输入核验、输出就绪等待和最终读取。

paired_heldout中原版与F处理同一250段、7239窗，保存logits可逐元素核对；二者均为单窗6167/7239、整段230/250。这证明该历史对照中的调用优化没有降低分类结果，不代表所有平台或未来改动都具有相同保证。

ablation区分forward、hardware_window和request等计时口径；这些时间不能直接替代最终ResNet18的独立SDK3.0841ms。最新完整PS/PL/屏幕应用的实现与实际任务时间以赛事工程和本次任务日志为准。
